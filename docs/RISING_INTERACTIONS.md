# 뜨는 상권 상호작용 계약

- 최종 앱은 Streamlit으로 실행한다. 왼쪽 지표와 지역 유형은 즉시 `rising_filters`에 반영하고, 상세조건의 기준·분기·업종은 제출 시 함께 반영한다.
- 지도 중앙의 자치구·지역 선택은 같은 세션 상태를 공유한다. 자치구가 바뀌면 기존 지역 선택을 지우고 양쪽 자치구 선택창을 동기화한다.
- 카카오 지도 컴포넌트는 순위 지역 경계와 서울 자치구 경계를 좌표 투영으로 그린다. 이동·확대 시 경계와 배지를 다시 배치한다. 전체 지역 표시를 켜면 현재 범위의 모든 지역 중심점을 추가한다. 대체 지도에도 동일한 경계·지역 자료를 전달한다.
- 순위 수치와 단위는 선택된 `metric`의 조회 결과에서 생성한다. 네 지표의 원본 값과 공식 순위 확인값은 기존 데이터 계약대로 구분한다.
- 지역 리포트를 열면 해당 지역·분기·업종의 실제 보고서 지표와 선택한 우선 분석 지표를 Ollama에 전달해 의견을 생성한다. 연결 실패 시 데이터 기반 대체 요약으로 표시하고 재분석 버튼을 제공한다. AI 문장은 금융·입지 결정의 단독 근거가 아니다.
- 중앙 선택, 상세조건, 지표 변경, 패널 접기, 리포트 AI 호출은 `tests/test_page_ui_flow.py`와 `tests/test_ollama_opinion.py`에서 확인한다.
