이 파일들은 로컬 실행 자료다. 원본 ZIP에서 최종 DB를 다시 만드는 Python 적재 파이프라인은 아직 없다. DB에 2021년 자료가 있어도 화면의 선택 가능 분기는 8개 지표·두 지역 유형이 모두 있는 분기만 허용한다.

## 이번 반영

- 공식 순위의 순서, 개별 값, 변화율의 출처를 행별로 구분한다. 공식 순위값을 원본 보고서 매출로 간주하지 않는다.
- 점포당 월평균 매출은 공식 보고서 확인값이 있는 지역만 그 값을 사용한다. 나머지는 같은 분기의 공개 원본 매출과 점포수로 계산한다. 과거 비교에도 각 분기의 점포수를 쓴다.
- 종합의견을 점포수·점포당 월평균 매출·면적당 유동인구의 3개 카드로 구성한다. 과거 분석 면적이 확인되지 않는 밀도 비교는 비교 자료 없음으로 표시한다. PDF 종합의견에도 같은 세 지표를 사용한다.
- 지표와 업종 선택을 가로 4칸으로 설정한다.
