이 파일들은 로컬 실행 자료다. 테스트 프로젝트의 Python 적재기를 scripts/import-raw.py와 scripts/import-details.py로 옮겼다. 이는 현재 화면이 읽는 스냅샷 스키마를 재생성하며 최종 정규화 스키마를 구현한 것은 아니다. DB에 2021년 자료가 있어도 화면의 선택 가능 분기는 8개 지표·두 지역 유형이 모두 있는 분기만 허용한다.

## 이번 반영

- 공식 순위의 순서, 개별 값, 변화율의 출처를 행별로 구분한다. 공식 순위값을 원본 보고서 매출로 간주하지 않는다.
- 점포당 월평균 매출은 공식 보고서 확인값이 있는 지역만 그 값을 사용한다. 나머지는 같은 분기의 공개 원본 매출과 점포수로 계산한다. 과거 비교에도 각 분기의 점포수를 쓴다.
- 종합의견을 점포수·점포당 월평균 매출·면적당 유동인구의 3개 카드로 구성한다. 과거 분석 면적이 확인되지 않는 밀도 비교는 비교 자료 없음으로 표시한다. PDF 종합의견에도 같은 세 지표를 사용한다.
- 지표와 업종 선택을 가로 4칸으로 설정한다.

## 아직 검증되지 않은 항목

- 실제 브라우저의 하단 여백, 배지·경계 호버, 카카오 인증, 패널 접기와 좁은 화면 배치. AppTest는 CSS·지도를 검증하지 않는다.
- 별도 DB에 원본 ZIP을 두 번 적재해 observations 115,295행, report_details 966,605행, report_industries 556,827행을 재현했다. 기존 복사본과 지표별 관측 행 수·합계가 일치하고 SQLite 무결성 검사가 통과했다. 최종 정규화 스키마로의 이식은 남았다.
- 공식 스냅샷의 확인 시각과 증거.
- 상세조건 취소의 실제 브라우저 동작, PDF 시각적 배치와 화면 대조, 전체 보고서 항목.
