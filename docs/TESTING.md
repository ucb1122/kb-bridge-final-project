# 테스트 안내

## 기본 검증

저장소 루트에서 다음 명령을 실행한다.

~~~powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m compileall -q app.py app_pages kb_bridge
~~~

자동 테스트는 설정 경로와 SQLite 계약, 원본·공식 화면 수치의 우선순위, 보고서 계산, 금융 입력의 경계값, Streamlit 화면 실행을 확인한다. `data/local/` 스냅샷이 없으면 해당 자료를 요구하는 회귀 테스트는 건너뛴다. 로컬 자료를 준비하려면 README의 실행 절차를 따른다.

## 화면 확인

- 뜨는 상권: 자치구·지역 유형·분기·업종 조건을 바꿔 순위, 지도 배지, 보고서의 지역과 기간이 일치하는지 확인한다.
- 내 상권 분석: 사업 운영·창업 준비 모드, 행정동 전체와 공식 상권, 보고서 다섯 탭의 값과 출처를 확인한다.
- 보고서 그래프: 페이지를 스크롤해도 그래프가 확대·이동되지 않고 값과 분기 레이블을 읽을 수 있는지 확인한다.
- 지도: 카카오 키와 허용 도메인을 설정한 브라우저에서 경계·마커·선택 동작을 확인한다. 키가 없을 때의 대체 배경지도와 목록 선택도 확인한다.
- 금융 시나리오: 입력값과 가정값의 출처, 월 현금흐름과 상환액 계산을 확인한다. 실제 승인이나 상담 접수 결과처럼 보이지 않아야 한다.

공식 화면 한 사례가 일치하더라도 모든 서울 지역·분기의 일치를 뜻하지 않는다. 수치 회귀 사례마다 원본 스냅샷과 기대값을 함께 기록한다.
