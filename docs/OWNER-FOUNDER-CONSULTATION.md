# 창업 준비 금융상담 화면

- 이슈: #30
- 진입: 내 상권 분석에서 **창업을 준비중이에요**를 선택하고 지역 보고서를 연 뒤 **KB 영업점 금융상담**을 누른다.
- 지역·업종·분기: 현재 보고서와 동일한 `kind`, `code`, `quarter`, `industry`로 `/api/rising/report`를 다시 조회한다. 지도 좌표도 해당 지역의 `observations` 행에서 API가 반환한 값을 사용한다. 유효하지 않거나 없는 지역이면 진행하지 않는다.
- 자금: 창업비용과 자기자금은 사용자가 입력한 값만 합산한다. 공란은 미입력으로 표시한다. 추가 준비액은 `max(0, 합계 비용 - 자기자금)`이다. 금융기관의 대출 가능 금액이 아니다.
- 지원 안내: `frontend/shared/finance/founder-support.json`은 사용자 제공 이전 프로젝트 ZIP의 2026-10-23 공식 공개자료 검토본이다. 창업 전 컨설팅과 사업자등록 후 확인할 상품을 구분한다. 상품 조건·접수 여부는 공식 링크에서 다시 확인한다.
- 영업점: `frontend/shared/finance/kb-branches.json`의 KB 공식 지점검색 2026-10-22 스냅샷 283곳을 실제 위경도의 직선거리로 정렬해 세 곳을 보여준다. 거리와 주소는 지점 방문 가능 시간이나 상담 가능 여부를 보증하지 않는다.
- 상담 메모: 현재 화면에서만 작성하며 서버나 은행으로 전송하지 않는다. 인쇄 기능으로 PDF를 저장할 수 있다. 실제 상담 예약·접수는 연결되지 않았다.

실제 자료로 시험하려면 `data/commerce.sqlite`를 준비한 뒤 `npm run dev`로 실행한다. 생성 DB가 다른 작업 디렉터리에 있을 때는 `DB_PATH`를 그 파일의 절대 경로로 지정한다. 테스트는 `npm test`를 실행한다.
