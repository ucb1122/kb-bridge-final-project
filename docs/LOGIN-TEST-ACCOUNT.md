# 테스트 계정 로그인

회원가입 화면 없이 로컬 테스트 계정 한 명으로 로그인한다. 로그인 ID는 `test1234`, 이메일은 `test1234@naver.com`, 표시 이름은 `홍길동`이다. 비밀번호는 저장소에 두지 않는다.

1. 프로젝트 루트에서 `npm run setup:test-user`를 실행한다.
2. 터미널에 사용할 비밀번호를 직접 입력한다. 입력한 문자는 `*`로 표시된다.
3. `npm run dev`로 서버를 실행하고 화면 오른쪽 위의 **로그인**을 눌러 모달에서 로그인한다. 로컬 시연에서는 비밀번호 없이 **테스트 계정으로 바로 로그인**할 수도 있다.

계정은 Git에서 제외되는 `data/users.sqlite`의 `users` 테이블에 저장된다. 명령을 다시 실행하면 같은 계정의 비밀번호를 바꾼다. 로그인 세션은 같은 DB의 `sessions` 테이블에 보관한다. 브라우저에는 세션 식별자만 HttpOnly 쿠키로 전달하며 `/api/auth/me`는 로그인 사용자 ID·이름·이메일·전화번호·상호를 반환한다.

로그인 상태에서는 헤더에 `홍길동님`이 표시된다. 이 버튼을 누르면 DB에서 읽은 아이디와 이메일, 로그아웃 버튼이 나타난다. 상담 신청 내용의 DB 저장은 별도 작업이다. 이후 저장 API는 요청 본문에 담긴 사용자 ID가 아닌 로그인 세션의 사용자 ID에 연결해야 한다.

테스트 계정 바로 로그인은 로컬 접속이며 `NODE_ENV=production`이 아닐 때만 허용한다. 계정이 없으면 랜덤 비밀번호 해시로 테스트 계정을 만들고, 이미 있다면 저장된 비밀번호를 바꾸지 않는다. 회원가입·이메일 찾기·비밀번호 찾기·간편 로그인은 화면 예시이며 비활성화되어 있다.
