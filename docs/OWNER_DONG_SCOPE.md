# 내 상권 분석의 행정동 집계 기준

- 기본 분석 단위 **행정동 전체**는 `data/local/commerce.sqlite`의 `observations`에서 `kind='dong'`, 선택 분기, 행정동 코드를 함께 적용해 읽는다.
- 전체 업종 점포수·분기 추정매출·유동인구는 각각 `stores`, `sales`, `footfall` 원본 값이다. 이 값에 상권별 통계를 더하거나 위치 반경의 인허가 업소를 섞지 않는다.
- 업종 필터를 선택하면 점포수·매출은 동일 DB의 `report_industries`에서 선택 업종 코드를 집계한다. 유동·상주인구는 업종과 무관한 행정동 전체 값이다.
- 순위와 지도 표시는 같은 행정동 코드와 분기의 수치를 사용한다. 지도 경계는 `data/local/commerce-dong.geojson`의 코드가 일치하는 도형이다.
- **공식 상권 전체** 선택지는 기존 `owner-regional-data.json`의 상권별 집계를 사용하며 행정동 수치로 표시하지 않는다.

2026년 2분기 이문1동(`11230740`) 원본 확인값: 점포수 1,116개, 분기 추정매출 31,007,618,538원, 유동인구 집계 14,072,454명. 전분기 값은 각각 1,097개, 29,213,974,490원, 12,498,853명이다. 화면의 증감률은 원본 값으로 `(이번 분기−전분기)÷전분기×100`을 계산해 소수 첫째 자리까지 표시한다.

로컬 DB와 경계 파일은 Git에서 제외된다. `scripts/prepare_test_data.py`가 테스트 프로젝트의 검증된 스냅샷을 `data/local/`에 준비한다.
