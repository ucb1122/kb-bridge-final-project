# 금리 범위·비용 표시 검증 (2026-10-27)

실제 로컬 상품정보를 보완했다. 앞서 이미지 시안의 가상 금리·가상 수수료는 사용하지 않았다. 원본 공유 폴더·CSV는 변경하지 않았다.

## 동일 조건 비교가 가능한 경우

- KB 일반부동산 담보대출: 같은 신용·기간·자금용도의 COFIX 4종 공시표를 사용. 우대 없음 5.77~6.06%, 최대 우대 적용 4.87~5.16%. 전체 고객 범위가 아니라 4개 기준금리 선택지의 최저·최고다. 행별 원값도 화면에서 확인한다. 기존 개별 예시(신규 COFIX 6개월 4.88~5.78%)는 삭제하지 않았다.
- KB셀러론: 2026-04-07 쿠팡 공시 4.35%, 자동선정산 0.50%p 차감 후 계산 3.85%. 다른 마켓과 혼합하지 않는다.
- 지역재단 보증서대출: 2025-12-31 특정 서울시 협약 예시. 지원 전 4.56%는 기준 2.86+가산 1.70 계산, 지원 후 2.06%는 공시. 이차보전 2.50%p를 일반 금리우대와 구분한다.

## 분리된 범위가 공시되지 않은 경우

KB소상공인 신용대출의 3.63~5.64%와 우대 최대 2.60%p는 별개 정보로 안내한다. 예시에서 우대를 역산하지 않는다. 같은 원칙을 마이너스통장에 적용한다. 나머지 상품의 미공시 값도 임의로 만들지 않는다.

## 비용·서류

- 공식 면제/없음만 0원으로 표시. 미공시는 조건별 확인.
- 일반 인지세의 고객 부담: 5천만원 이하 0원, 초과~1억원 3만5천원, 초과~10억원 7만5천원, 10억원 초과 17만5천원. 상품 한도에 맞춘 요약과 전체 일반 구간표를 구분. 온택트의 공시 한도 3천만원에선 0원.
- 보증료 숫자는 기존 공시를 유지하며 개별 심사·협약 조건을 붙인다. 인지세 외 담보비용은 임의 수치화하지 않는다.
- 신용대출: 본문에 있는 5천만원 초과 신규의 자금 증빙과 기존 1억원 초과 자금용도 심사를 함께 보존.
- 서류를 기본 제출/확인·전자 수집·조건부·추가 확인으로 분류. 기관 공통 자료를 개별 필수자료로 바꾸지 않는다.
- 정책자금 2026년 4분기 금리표(2026-10-10 적용)를 공식 페이지와 재대조했다. 접수 중 여부를 금리표에서 추정하지 않는다.
