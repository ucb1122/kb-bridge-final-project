## 주의 (꼭 읽기)
- 02·03의 금리·한도 문구는 공식 안내를 **요약**한 것이며 실시간 상품 DB가 아닙니다. 개인 적용금리·자격·승인을 판정하는 데이터가 아닙니다.
- 02·03은 일부 상품이 겹칩니다(예: KB사장님+ 마이너스통장, KB 119plus). 03은 화면용 후보 목록으로 따로 만든 것입니다.
- 01의 중진공 기준은 중소기업 대상 정책자금 기준입니다. 소진공 소상공인 정책자금의 제외업종과 같은지는 확인되지 않았습니다.
- 01의 금리 0 표기를 무이자·현재 적용금리로 해석하지 않습니다.
