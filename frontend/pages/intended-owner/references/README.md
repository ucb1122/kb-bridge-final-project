# 상담서 양식 참고 자료

- 원문: 중소벤처기업부 「2020년 제조 중소기업 혁신 바우처 사업(2차) 지원계획 공고」의 참여기업 신청서, PDF 4쪽(인쇄 7쪽).
- 파일: `public-consulting-application-reference.pdf`. 원본을 변경하지 않고 보관.
- URL 및 확인일: `reference-sources.json`.
- 적용한 구성: 신청인·연락처를 표로 정리, 요청 분야와 금액 분리, 번호가 있는 구획 제목, 항목명/기입란 구분.
- 적용하지 않은 것: 과거 사업의 지원 자격·보조율·신청금액, 주민번호·사업자번호 수집, 법적 동의서/서명, 기관 로고·정부 신청서의 전체 문구.
- 실제 생성 문서는 KO-B가 독자 제작한 사전 상담용 시연 양식이다. KB 정식 신청서나 정부 지원사업 신청서를 대신하지 않는다.
- 서대문구의 2026년 전문상담 경영컨설팅 공고도 양식 첨부 여부를 확인했으나 파일을 내려받지 못해 원 양식으로 사용하지 않았다.
