# 폐업 위험 관찰 상권 연결 2026년 10월 27일

## 실행

저장소 루트에서 Python 환경에 `tools/requirements-closure.txt`의 라이브러리를 준비한 뒤 실행합니다.

```powershell
python pages/intended-owner/tools/build_closure_risk.py
node --test pages/intended-owner/tools/verify-closure-risk.mjs
```

기본 입력은 `data/의사결정.ipynb`와 `data/의사결정 지원/`입니다. 원본을 수정하지 않습니다.
화면이 읽는 계산 결과는 `pages/intended-owner/assets/closure-risk.json`입니다.
별도 확인용 CSV는 `data/local/decision-risk/`에 생성됩니다. 원본 CSV·노트북·DB를 Git에 추가하지 않습니다.
이미 결과 JSON이 있으면 웹 화면에는 Python 서버가 필요하지 않습니다. 재계산 뒤 브라우저를 새로고침합니다.

## 어떤 모델을 연결했는가

노트북 앞부분의 RandomForest/G 분류는 다음 해 G≥-1을 예측합니다. 이 결과를 폐업 위험으로 바꾸어 표시하지 않았습니다.
보고서가 채택한 폐업률 OLS와 노트북 마지막 셀 36의 단순 기준을 사용했습니다.
전처리는 원본 셀 5·6·9·10을 로컬 파일 경로로 실행합니다. Colab 설치·Drive 접근 셀은 실행하지 않습니다.
OLS는 numpy.linalg.lstsq로 절편과 상권 유형의 treatment dummy를 사용해 계산합니다. statsmodels의 동일 OLS 목적함수와 같습니다.
원본 셀과 파일 SHA-256은 결과 JSON의 provenance에 기록합니다.

2022~2023년 입력과 2024~2025년 폐업률 3,107행으로 학습한 뒤, 2025년 입력으로 2027년을 추정합니다.
입력은 현재 폐업률, log(1+연평균 전체 점포), 상권 유형입니다. 수동 퍼센트 가중치나 G지수 가산점은 없습니다.
G 산정 가능 표본을 사용하는 노트북의 표본 규칙은 유지합니다. 따라서 G 완전성은 대상 포함에 영향을 주지만 G 값 자체는 순위 산식에 넣지 않습니다.

전체 1,650개 중 평가 1,548개, 상위 10% 올림 155개, 자료미비 102개입니다.
점포 수는 4개 분기 평균, 폐업 수는 연간 합계입니다. 연평균 점포 10개 미만은 제외합니다.
동점은 상권코드 순서로 일관되게 정렬합니다. 지역 필터의 1~10번은 화면의 표시 순서이며 서울 전체 순위를 함께 표시합니다.

## 재현 확인

과거 입력연도만으로 학습한 검증 결과:
- 1년 뒤: 상위 10% 적중률 51.2903%, 고위험 포착률 20.4633%.
- 2년 뒤: 상위 10% 적중률 49.0323%, 고위험 포착률 19.5876%.

노트북 셀 36의 출력 51.3%·49.0%와 일치합니다. 검증의 고위험은 목표 연도 폐업률 상위 25%입니다.
보고서의 신뢰구간 부트스트랩은 이번 빌드에서 재계산하지 않았으며 화면에도 재계산된 것처럼 표시하지 않습니다.
화면 검사에서 모든 지역 코드 결합, 순위, 독립 산식 재계산, 검색·필터, 자료미비 표기를 확인합니다.
