# 공용 금융 안내 자료

`products.json`과 `details-*.json`은 금융상품 안내 화면의 목록과 상세 조건에 사용하는 검토된 공개자료 스냅샷입니다. `kb-branches.json`은 금융상품 안내, 우리 가게 회복 플래너, 내 상권 분석의 상담 화면이 함께 읽는 영업점 자료입니다.

원본 자료와 출처·검토 기록은 `pages/guide/sources/`, `pages/guide/catalog-sources.md`에 보존합니다. 수치와 조건을 바꿀 때는 공식 출처의 기준일을 확인하고, `pages/guide/DATA-MANIFEST.json` 및 `pages/intended-owner/DATA-MANIFEST.json`의 해시를 갱신한 뒤 각 화면의 검증 도구를 실행하세요.

이 파일들은 안내용 정적 자료이며 실시간 금리, 신청 자격 판정, 상담 접수 상태를 뜻하지 않습니다.
